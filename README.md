# 叠石匠 · 假山叠石设计与预览系统

面向园林假山工程的网页版叠石设计工具：石料库管理、拖拽叠石、稳定校核、GTAO 光影预览、
透光孔分析、施工交底单导出。纯前端 TypeScript + three.js，数据存 IndexedDB，无需后端。

## 启动

```bash
npm install
npm run dev      # 开发，默认 http://127.0.0.1:5173
npm run build    # 类型检查 + 生产构建
npm run preview  # 预览生产构建
```

首次打开会自动程序化生成 30 块测试石料（太湖石 12 / 黄石 10 / 英石 8）。

## 六大页面

| 页面 | 功能 |
|---|---|
| 石料库 | 按石种/编号管理，每块带三维网格、重量、体积、产地、堆场；太湖石记录穿透孔道参数 |
| 叠石设计 | 选石拖放、R 键旋转、自动贴附下方接触面、防穿插、接触面积过小标黄、八法手法标签与呆板提醒 |
| 稳定校核 | 自下而上逐块算重心/支撑凸包/抗倾覆系数，危险标红，悬挑提示铁件，压顶石专项 K 校核 |
| 光影预览 | GTAO 环境光遮蔽、季节/时刻/天气光照、水面、多视点透光孔统计、AO 离线射线校验 |

## 两条可信度主线

### 1. 洞的明暗 —— GTAO + 离线射线校验

- **GTAO**（`src/render/gtao.ts`）：基于地平角（horizon angle）的环境光遮蔽，弯曲法线
  （bent normal）驱动天光遮挡，带时域累积（ping-pong RT + 重投影 + 法线钳制）与多次反弹
  近似，使洞口由外到内层层变暗而非平灰。半分辨率 AO 控制开销。
- **离线参考**（`src/render/referenceAo.ts`）：余弦加权半球蒙特卡洛射线（每探针 96 条，
  空间网格加速），与同预算 GTAO 对照值逐探针比较。光影预览页一键运行，
  **平均绝对误差目标 < 5%**（实测约 1.5%）。

### 2. 稳定计算 —— 可与手算对照

- 重心：网格有向体积（散度定理）加权，随落位变换到世界坐标。
- 支撑面：接触点在水平面投影的二维凸包（Andrew 单调链）。
- 抗倾覆系数：`K = (d稳 + d倾) / (d稳 − d倾)`，绕支撑凸包最不利边取最小值；
  重心越出支撑面时 K 为负。压顶石强制 `K ≥ 1.5`（可在设置页调整）。
- 计算口径完整列在稳定校核页“手算对照”卡片，可逐项与手算核对。

## 几何生成（确定性，网格不入库）

`src/geometry/`：

- 所有随机来自种子化 `mulberry32`，同一 `seed` 永远重建同一网格，故 IndexedDB 只存参数。
- **太湖石**：椭球 SDF + 有界圆柱隧道差集（真通孔）+ fbm 溶蚀，Surface Nets 等值面提取。
- **黄石**：二十面体 + 折叠/值噪声变形，非索引 + 平面法线，呈现方折块面。
- **英石**：拉长二十面体 + 脊状噪声，瘦高尖棱、褶皱皱感。

## 性能

- 几何按石料缓存复用，表面点采样做空间哈希 broadphase。
- GTAO 半分辨率 + 时域累积，静态场景逐帧只做少量增量。
- 各三维页面右上角实时显示 FPS。30 石场景在独立 GPU 上目标稳定 60 帧
  （无头软件渲染 SwiftShader 仅个位数，属环境限制，不代表真实硬件表现）。
